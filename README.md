# Mechanical Engineering Portfolio

Welcome to my professional portfolio. This space serves as an organized log of my independent academic projects, engineering design practice, and physics problem solving.

## Overview

The repository is built to document my journey through core mechanical concepts and spatial design. Every project here reflects hands on learning and a commitment to mastering engineering fundamentals from the ground up.

## Repository Structure

The cad designs folder contains screenshots, layout documentation, and component breakdowns of three dimensional mechanical models.

The research notes section houses structured breakdowns of classical mechanics, kinematics, and core physical principles.

## Tools And Software

My current workflow relies on Tinkercad for building and visualizing spatial geometry, alongside rigorous analytical problem solving and mathematical derivation for physics applications.
