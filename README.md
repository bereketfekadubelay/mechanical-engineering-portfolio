# Mechanical Engineering Portfolio

A personal academic repository documenting my preparation for undergraduate mechanical engineering studies, focusing on fundamental physics, spatial geometry, and design iterations.

## 🎯 Overview
This portfolio serves as an organized log of my independent academic projects, engineering design practice, and physics problem-solving as a Grade 12 student.

## 📂 Repository Structure
- **`/cad-designs`**: Screenshots and layout documentation of 3D mechanical components and spatial geometry modeled using **Tinkercad**.
- **`/physics-notes`**: Structured breakdowns of classical mechanics, kinematics, and core physical principles.

## 🛠️ Tools & Software
- **Design & Modeling:** Tinkercad (for learning basic 3D assemblies and spatial relationships).
- **Analysis:** Analytical problem-solving and mathematical derivation.
